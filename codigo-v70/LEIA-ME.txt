KIMETSU LEGACY v77
Código-fonte e testes

Kimetsu_Fix_v77_Completo.mcaddon inclui o Behavior Pack e o Resource Pack,
ambos na versão interna 1.0.59. Importe o arquivo no Minecraft Bedrock,
ative os dois pacotes e habilite APIs Beta no mundo.

Selecione Menu Kimetsu ou o livro e use o item. No toque, use o botão
Abrir menu. Agache ao usar para selecionar a interface clássica. Para
voltar ao painel, escolha Menu em painel.

Personagens novos escolhem Pele, Cabelo e Olhos no primeiro login.
Confirme a aparência para abrir o contrato do Caçador. Depois, use
o Menu Kimetsu normalmente.

As pastas Kimetsu Fix Be e Kimetsu Fix Re contêm os arquivos alterados em
relação à v69. Os pacotes inteiros podem ser extraídos do .mcaddon completo.

Teste automatizado em Node.js
Use Node 24 e aponte KIMETSU_BP para a pasta do Behavior Pack completo,
com todos os arquivos e dependências internas extraídos, inclusive os que
não mudaram. Execute node --test testes/*.test.mjs.

Exemplo:
KIMETSU_BP="/caminho/Kimetsu Fix Be" node --test testes/*.test.mjs

GameTest no Bedrock dedicado
Use um mundo de teste separado, com Beta APIs habilitadas. Copie bedrock.js
para scripts/stats_test.js no pack de teste, importe "./stats_test.js" em main.js
e adicione o módulo @minecraft/server-gametest 1.0.0-beta ao manifesto de teste.
O teste cria jogadores simulados, altera regras apenas nesse mundo isolado e
salva uma ficha para conferir a leitura após o reinício do servidor.
Para testar o uso nativo dos itens, instale bedrock-menu.js da mesma forma,
no lugar de bedrock.js. O teste simula as respostas dos formulários.

Use bedrock-hibridos.js ou bedrock-transformacao.js no lugar de bedrock.js
para testar os Híbridos no Bedrock. Para testar o sistema de treinos,
use bedrock-treino-respiracao.js. O relatório atual está em
docs/RELATORIO-TREINO-RESPIRACOES-V75.md.

Para testar a oficina no servidor, use bedrock-aparencia.js. A teoria,
o fluxo de uso, o catálogo e os resultados de testes estão
em docs/RELATORIO-APARENCIA-INICIAL-V77.md.

Use o Resource Pack 1.0.59 do .mcaddon completo para testar a interface no
cliente. No servidor dedicado, configure os dois pacotes na versão 1.0.59 na
lista de pacotes do mundo.
